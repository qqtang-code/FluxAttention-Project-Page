# FluxAttention-Project-Page
Flux Attention: Context-Aware Hybrid Attention for Efficient LLMs Inference

## GitHub Pages Deployment

This repository is configured to deploy automatically to GitHub Pages via GitHub Actions.

### 1. Enable GitHub Pages

In your GitHub repository:

1. Go to `Settings` -> `Pages`.
2. Under `Build and deployment`, set `Source` to `GitHub Actions`.

### 2. Trigger Deployment

Any push to the `main` branch will trigger deployment.
You can also run it manually from the `Actions` tab using `Deploy static site to GitHub Pages`.

### 3. Visit Your Site

After the workflow succeeds, your site will be available at:

`https://qqtang-code.github.io/FluxAttention-Project-Page/`
